# Onboarding

New to the Riverside donor tools? Start here.

- Donor data lives in `data/`. It's synthetic: real client data never goes in this repository.
- The duplicate check runs before every appeal (`docs/runbook.md`).
- The web form's cursor code is in `src/`. CI checks it seperately (`ci/checks.yml`).
- The lead is named in `docs/STATUS.md`.
